# 架构决策记录索引

## ADR-001：三层架构分层

**状态**：已采纳 | **领域**：工程架构

核心业务层、平台适配层、共享层三层分离，核心层对 OpenCode SDK 零依赖。

---

## ADR-002：模板与业务逻辑分离

**状态**：已采纳 | **领域**：模板体系

Agent 指令和输出模板独立于业务代码管理，支持用户自定义覆盖和运行时回退。

---

## ADR-003：构建配置标准化

**状态**：已采纳 | **领域**：工程架构

统一构建流程（TypeScript 编译 → Agent 生成 → 打包分发），`build-agents.cjs` 作为模板编译入口。

---

## ADR-004：测试组织策略

**状态**：已采纳 | **领域**：质量保障

单元测试按业务域组织于 `src/__tests__/`，集成测试独立于 `e2e/` 目录，支持三种粒度独立执行。

---

## ADR-005：根目录架构公约

**状态**：已采纳 | **领域**：工程架构

根目录按功能域组织（`src/` 源码、`e2e/` 集成测试、`dist/` 构建产物），`.sddu/` 存储方法论产物。

---

## ADR-006：模块 API 契约

**状态**：已采纳 | **领域**：工程架构

所有公共类型从 `index.ts` 统一导出，错误处理使用 `Errcode` 枚举 + 标准化错误消息。
