# ADR-001: 概览 / 详情分层结构 — 三主体 × 两层粒度，替代单层 8 章混合结构

## 状态
ACCEPTED

## 背景

上游 Feature FR-ROADMAP-TPL-001（v4.1.0）已把 `.sddu/ROADMAP.md` 收敛为固定的 8 个 H2，但章节**内部的组织逻辑仍是扁平的、混装的**。discovery 诊断出六个问题，其中三个核心问题同源：

- **Q-001 横切杂物箱**：旧「§7 下一步行动」把技术债 / 决策 / 执行批次 / 版本级行动混装于一章，与版本（§2/§5）、特性（§3）、优先级（§4）三方发生归属侵占。
- **Q-002 双时间轴打架**：版本轴（§2 版本总览 / §5 版本规划详述）与「立即 / 短期 / 中期 / 远期 + Phase / Wave」（§7）并存，同一信息两种表达必漂移。
- **Q-004 独立依赖风险章破坏三主体闭合**：依赖 / 风险被抽成独立 §6，与其真正归属的版本 / 特性脱节，读者需跨章拼装同一实体的完整信息。

**结构性根因**：旧 8 章的划分维度是「**文档块**」（总览 / 详述 / 风险 / 行动 / 修订），而非「**管理三主体**」（版本 / 特性 / 问题）。维度不对齐，必然出现横切容器与双时间轴。

用户已拍板（D1 / D4）：采用「概览 / 详情分层」，清单层用「XX 清单」、详情层用「XX 详情」。spec FR-001 / FR-002 已把该结构固定为 8 H2 + 8 zone。

## 决策

采用**三主体 × 两层粒度**的分层结构，共 8 个 H2：

| 层 | 章节 | 粒度 |
|----|------|------|
| 首尾 | §1 项目愿景与定位 / §8 修订记录 | 项目级 |
| 清单层（概览） | §2 版本清单 / §3 特性清单 / §4 问题清单 | 粗表：一行一条目，只放索引级字段 |
| 详情层 | §5 版本详情 / §6 特性详情 / §7 问题详情 | 展开：entry 键控，承载观点与台账 |

关键设计取舍：

1. **按管理三主体切分**（版本 / 特性 / 问题）替代按文档块切分——同一实体在「清单 + 详情」两章内闭合，不再跨章拼装。
2. **依赖与风险取消独立章**，按归属规则融入三主体（版本级 → §5 entry 字段；特性级 → §6 entry 字段；项目级 → §4/§7 类型 = 风险/依赖），消除横切容器（Q-004）。
3. **优先级方法论淘汰**（Q-002）：RICE / Top N / Phase / Wave / 立即-短期-中期-远期 全部移除，P0/P1/P2 降为 §6 entry 字段，只保留单一版本时间轴。
4. **粗略 / 具体两种读模式**：读者可只读清单层把握全貌，再按需下钻详情层——与外部 roadmapping 工具的「列表视图 ↔ 详情视图」同构。
5. **命名口径统一**（D4）：清单层一律「XX 清单」、详情层一律「XX 详情」，读者仅凭章节名即可判断粒度。

## 后果

**正向**：
- Q-001 / Q-002 / Q-004 从结构层面消解——没有横切容器、没有第二时间轴、没有脱离主体的依赖风险章。
- 三主体对称：版本 / 特性 / 问题各有「清单 + 详情」，learnability 高，下游可按稳定语义定位。
- 问题获得独立身份承载位（§4/§7 + P-xxx 登记制），未立项提案获得承载位（§3/§6 + PR-xxx）。
- 章节集合与顺序仍固定（8 H2），v4.1.0 的「集合与顺序不漂移」保证不回退。

**代价 / 残余风险**：
- 章节命名与旧版完全不同 → 旧产物含旧 zone 时不兼容，须走 FR-012 非破坏迁移（见 ADR-002 与 plan §4.6）。
- 详情层 entry 字段较旧版增多（§6 达 7 个字段）→ 模板行数与填写负担上升，由行数预算与「禁实现明细」（EC-010）约束。

## 备选方案与否决理由

| 备选 | 否决理由 |
|------|---------|
| 保留单层 8 章，仅删 RICE / 加图（方案 C） | Q-001 / Q-002 / Q-004 均无法消解，与 D1~D4 拍板结论正面冲突 |
| 三主体各一章（共 3 章 + 首尾） | 版本 / 特性 / 问题的清单与详情混于一章，章节内仍需分区，粗略 / 具体两种读模式无法分离 |
| 按「文档块」保留独立依赖风险章，只做字段规整 | 依赖风险脱离主体，Q-004 未解；跨章拼装成本依旧 |
| 增加第四主体（如「提案」独立成主体） | 提案尚未立项（无 state.json），不足以成独立主体；以 PR-xxx 挂入特性清单 / 详情即足（FR-007） |
