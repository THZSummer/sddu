# ADR-002: preserve 区投影图随区重建（弃逐字保留）

## 状态
ACCEPTED

## 背景
issue-list pie（问题类型分布）与 revision-log timeline（修订时间线）是对其下方表格的**实时投影**（含 `<<数量>>` / 版本条目），却位于 `mode="preserve"` 区并按「逐字保留」合并（P-038）。增量更新追加新行后，表格合并新行而图表冻结，计数 / 时间线逐渐与表格脱节。§5.7 自检与模板 NOTE 5 均写「preserve 区图逐字保留」，与投影图的实时性冲突。

## 决策
按图表性质区分合并语义：
- **投影类图表**（issue-list pie / revision-log timeline，含 `<<数量>>` 或数据条目）→ **随区重建**：合并时按最新表格内容重建图表计数 / 时间线；
- **结构性图表**（version-detail / feature-detail / issue-detail 的 graph LR，仅示意关系）→ 维持「随区保留」。

同步修正 §5.4.4 Step C2 与 §5.7 自检清单的「preserve 区图逐字保留」表述为「投影类图随区重建、结构类图随区保留」。

## 后果
- 优点：图表与表格始终一致，消除增量漂移；规则口径自洽。
- 代价：preserve 区合并语义需区分「表格行（行自然键逐字保留）vs 投影图（随区重建）」两类，规格文本 +1 处分类说明。
- 边界：仅投影类图表重建；结构性图表与表格行的「逐字保留」语义不变。
